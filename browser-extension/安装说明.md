# ScholarVPN 浏览器代理插件 · 安装说明

**只在浏览器里生效**的代理插件（Chrome / Edge）。启用后浏览器流量经服务器出口，
不安装系统组件、不改系统网络、不影响其他软件，可与整机版客户端同时使用。

---

## 一、开始前先找管理员要三样东西

| # | 内容 | 说明 |
|---|---|---|
| 1 | 服务器地址与端口 | 通常是 `IP:8443`（HTTPS 代理入口） |
| 2 | 代理账号与密码 | 服务端 `--proxy-user` / `--proxy-pass` |
| 3 | `ca.cert.pem` 证书文件 | **仅当服务器用自签证书时需要**；若服务器用的是正规证书（如 Let's Encrypt），跳过证书步骤 |

---

## 二、安装四步

### 第 1 步：导入服务器证书（只有自签证书才需要）

1. 把管理员给你的 `ca.cert.pem` 放到**本文件夹**里；
2. 右键 `导入证书(管理员运行).bat` → **以管理员身份运行**，看到"导入完成"即可；
3. **完全退出浏览器**（任务管理器里确认没有 `msedge.exe` / `chrome.exe` 残留），再重新打开。

> 手动方式（管理员命令行）：`certutil -addstore -f Root ca.cert.pem`
> 如果跳过这一步，插件启用后会报 `ERR_PROXY_CERTIFICATE_INVALID`（证书不受信任）。

### 第 2 步：加载扩展

1. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`；
2. 打开右上角 **开发者模式**；
3. 点 **加载已解压的扩展程序**，选择**本文件夹**（就是包含 `manifest.json` 的那个文件夹）；
4. 工具栏出现盾形图标即加载成功。

### 第 3 步：填写配置（点图标打开弹窗）

| 项 | 填什么 |
|---|---|
| 代理协议 | `HTTPS 代理（TLS 加密，推荐）` |
| 服务器地址 | 管理员给的 IP 或域名 |
| 端口 | `8443`（以管理员给的为准） |
| 用户名 / 密码 | 管理员给的代理账号密码（两个都要填） |
| 代理范围 | 一般选「全部流量走代理」；下方列表可填要**直连**的域名（如公司内网） |

### 第 4 步：开启并验证

1. 打开弹窗右上角的**开关**，图标角标出现 `ON`；
2. 点 **「检测出口 IP」**：显示服务器 IP 即为成功（若显示你自己的宽带 IP，说明开关没打开）。

---

## 三、注意事项

- **默认不启动**：装好后开关是关的，需要时手动打开即可；你的开关状态会被记住，重启浏览器不丢。
- **只影响这个浏览器**：不代理其他浏览器、其他软件和系统网络；关掉开关立即恢复直连。
- **Chrome 与 Edge 要各装一次**：两个浏览器是独立的，配置也需要各填一遍（证书是系统级的，不用重复导入）。
- **导入证书 = 信任该服务器**：只导入你信任的服务器证书。若服务器使用正规证书，则无需导入任何东西。
- **密码存放位置**：浏览器扩展的本地存储（明文，同机其他程序理论上可读）——请使用专用的代理密码，不要复用你在别处用过的密码。
- **不要用无痕窗口测试**：插件代理对普通窗口生效，无痕窗口不生效。
- 与整机版客户端（Windows/Android 的 ScholarVPN）**互不冲突**，可以同时开。

## 四、常见问题

| 现象 | 处理 |
|---|---|
| 开关打开后网页全打不开 | 服务器是否在运行、端口是否放行；把开关关掉可先恢复上网 |
| 一直弹认证框 | 用户名/密码是否与管理员的配置一致（注意大小写） |
| `ERR_PROXY_CERTIFICATE_INVALID` | 证书没导入或没重启浏览器 → 重做第 1 步，并完全退出浏览器后重开 |
| 部分网站打不开 | 检查"代理范围"与域名列表；列表项只写域名（如 `example.com`），不要带 `http://` 或路径 |
| 图标角标没有 ON | 开关没打开，或服务器地址/端口填错 |

---

## 五、更新与卸载

- **更新**：用新版本的文件夹替换后，到扩展页点该插件的 **重新加载** 按钮即可；扩展 ID 不变，配置与证书都不需要重做。
- **卸载**：扩展页 → **移除**。如不再需要，可顺手删除已导入的证书：
  管理员命令行执行 `certutil -delstore Root "ScholarVPN CA"`。

---

## 六、进阶（可选）：预填配置，免去手动填写

把 `config.json.example` 复制为 `config.json`，填入服务器地址/端口/账号密码后重启浏览器，
弹窗里就会自动带好这些值（`applyOnStartup` 保持 `false` 即"仍由你手动开关"）。
`config.json` 含密码，请勿外传或提交到代码仓库。
