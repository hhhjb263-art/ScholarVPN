# 后台管理 Web 客户端使用说明

> 给 `vpn_controller` 的 JSON API 套一层网页，并带管理员登录。
> 零第三方依赖：只用 Python 3 标准库（http.server / urllib / sqlite3 / hashlib / ssl）。
> 当前公网示例：`https://scholarvpn.homes/`。

---

## 1. 安全模型

```text
浏览器 ──HTTPS──▶ webadmin（管理员会话 + CSRF）
                     │ 127.0.0.1:18081，服务端注入 Bearer
                     ▼
                vpn_controller
```

- 管理员账号存 SQLite：`tools/webadmin/data/webadmin.db`
- 密码：`hashlib.scrypt` + 每用户随机盐，数据库只存 hash
- 会话：服务端随机 256-bit 令牌，数据库只存 SHA-256；Cookie 为
  `HttpOnly; Secure; SameSite=Strict`
- CSRF：登录后所有写操作必须带 `X-CSRF-Token`
- 登录失败限速；登录错误统一提示，避免用户名枚举
- **不开放公开注册**：首个管理员由服务器 root 用 `manage.py` 创建，后续账号由已登录管理员添加
- 登录后可在“账号”里修改自己的密码；改密后注销全部会话
- **中转管理令牌只保存在服务端**，用于访问 `127.0.0.1:18081`，浏览器拿不到
- 所有 SQL 使用 `?` 参数化，不拼接用户输入（防 SQL 注入）

---

## 2. 前置条件

1. `vpn_controller` 在跑：
   ```bash
   ss -ltn | grep -E ':18081|:19090'
   ```
2. 有中转管理令牌（首次初始化/服务端代理用）：
   ```bash
   cd /root/ScholarVPN/server
   ./admin-relay.sh token
   ```
3. 至少一台 agent 在线（否则页面能开，但服务器列表为空）：
   ```bash
   ./admin-relay.sh status
   ```

## 3. 启动

### 3.1 本机/开发

```bash
cd /root/ScholarVPN/tools/webadmin

# 令牌只在服务端使用；首个管理员用 manage.py create-admin 创建
ADMIN_TOKEN="$(cd ../../server && ./admin-relay.sh token)" \
python3 app.py --listen 127.0.0.1 --port 8080
```

打开 `http://127.0.0.1:8080/`，会跳转到 `/login`；首次点“创建第一个管理员”。

### 3.2 生产 HTTPS（推荐）

```bash
cd /root/ScholarVPN/tools/webadmin
ADMIN_TOKEN="$(cd /root/ScholarVPN/server && ./admin-relay.sh token)" \
python3 app.py --listen 0.0.0.0 --port 8443 \
  --tls-cert /root/ScholarVPN/server/tls/fullchain.pem \
  --tls-key  /root/ScholarVPN/server/tls/privkey.pem
```

或使用封装脚本（自动读取 `server/admin-domain.env` 和服务端中转令牌）：

```bash
cd /root/ScholarVPN/server
./start-admin-web.sh
```

浏览器打开 `https://scholarvpn.homes/`；首个管理员先按 4.1 在服务器创建。

### 3.3 systemd

当前公网部署的 unit：

```bash
systemctl status scholarvpn-admin-web
journalctl -u scholarvpn-admin-web -f
```

最小示例：

```ini
[Unit]
Description=ScholarVPN Admin Web (HTTPS)
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/ScholarVPN/tools/webadmin
EnvironmentFile=-/root/ScholarVPN/server/admin-domain.env
ExecStart=/root/ScholarVPN/server/start-admin-web.sh
Restart=on-failure
RestartSec=3
NoNewPrivileges=true
PrivateTmp=true
ProtectSystem=full
ReadWritePaths=/root/ScholarVPN/server/logs /root/ScholarVPN/server/run

[Install]
WantedBy=multi-user.target
```

> `start-admin-web.sh` 会在服务端读取 `relay_admin_token.txt`；不要把令牌写进
> unit 或前端。数据库目录 `tools/webadmin/data/` 必须是服务运行用户可写，权限 700。

### 3.4 参数/环境变量

| 参数 | 环境变量 | 默认 | 说明 |
|---|---|---|---|
| `--listen` | `WEBADMIN_BIND` | `127.0.0.1` | 监听地址 |
| `--port` | `WEBADMIN_PORT` | `8080` | 监听端口 |
| `--controller` | `CONTROLLER_URL` | `http://127.0.0.1:18081` | 上游 controller 地址 |
| `--controller-ca` | `CONTROLLER_CA` | 空 | 上游 HTTPS 的私有 CA |
| `--token` | `ADMIN_TOKEN` | 空 | 中转管理令牌，**仅服务端使用** |
| `--db` | `WEBADMIN_DB` | `data/webadmin.db` | SQLite 路径 |
| `--cookie-secure` | `WEBADMIN_COOKIE_SECURE` | HTTPS 时开 | Cookie 是否带 `Secure` |
| `--tls-cert` | `WEBADMIN_TLS_CERT` | 空 | HTTPS 证书链 |
| `--tls-key` | `WEBADMIN_TLS_KEY` | 空 | HTTPS 私钥（0600） |
| `--vpn-public-ip` | `VPN_PUBLIC_IP` | 空（自动探测） | VPN 服务器**对外地址**（公网 IP 或域名），页面展示供复制 |
| `--vpn-public-port` | `VPN_PUBLIC_PORT` | `51820` | VPN 对外端口，与上面的 IP 拼成 `IP:端口` |

> 不要设置 `WEBADMIN_AUTO_TOKEN`（已废弃）。浏览器不应接触任何中转令牌。

**关于 `VPN_PUBLIC_IP`**：后台与 VPN 同机部署时，controller 报告的 agent 源地址是
`127.0.0.1`，对客户端毫无用处；页面要展示的是**从外网能连上的地址**。
留空时 webadmin 会在首次访问 `/api/meta` 时向公共回显服务询问出口 IP
（`api.ipify.org` / `icanhazip.com` / `ifconfig.me`，任一成功即可，结果缓存 10 分钟）。
服务器无外网访问时探测会失败，此时请显式指定：

```bash
VPN_PUBLIC_IP=vpn.example.com ./app.py ...        # 或写进 systemd 的 Environment=
```

## 4. 首个管理员 / 登录 / 改密码

### 4.1 首个管理员（服务器端创建，不开放注册）

网页**没有注册入口**。第一个管理员在服务器上创建（需要能读写
`tools/webadmin/data/` 的用户，通常是 root）：

```bash
cd /root/ScholarVPN/tools/webadmin
python3 manage.py create-admin admin
# 按提示输入密码（至少 10 位，不会进入 shell history）
```

用户名规则：3–32 位字母/数字/`._-`。

然后打开：

```text
https://scholarvpn.homes/login
```

还没创建管理员时，登录页会提示执行上面的命令。

### 4.2 登录/登出

- 登录：`https://scholarvpn.homes/login`
- 登出：右上角“退出”（POST + CSRF）
- 会话：12 小时无操作过期，最长 7 天；Cookie 为 HttpOnly/Secure/SameSite=Strict

### 4.3 添加管理员

登录后点右上角“管理员”，输入新用户名/密码，点“创建”。新账号不会自动登录，
需要到 `/login` 登录。

### 4.4 修改自己的密码

登录后点右上角“账号”：

1. 输入当前密码；
2. 输入新密码（至少 10 位）并确认；
3. 点“修改”。

修改成功后该账号的**全部会话失效**，页面跳回登录页，用新密码重新登录。

### 4.5 忘记密码 / 账号恢复

在服务器上执行：

```bash
cd /root/ScholarVPN/tools/webadmin
python3 manage.py list
python3 manage.py reset-password <用户名>
# 或新建账号：
python3 manage.py create-admin <用户名>
```

密码通过终端交互输入，不进入 shell history。重置密码会删除该用户的全部会话。

## 5. 界面操作

### 5.1 布局

```text
┌─────────────────────────────────────────────────────────┐
│ ScholarVPN 后台管理  管理员：alice  [账号] [管理员] [退出] [刷新] │
├──────────┬──────────────────────────────────────────────┤
│ 服务器    │ 公钥/监听信息 / 未消费令牌                     │
│ 公网 1.2.3.4:51820 [复制]                                │
│ ● vpn-1  │  [复制] [申请] [导出 JSON]                    │
└──────────┴──────────────────────────────────────────────┘
```

左栏「服务器」标题下方会显示 **VPN 公网地址**（`IP:端口`），旁边有「复制」按钮——
客户端配置里要填的就是这个地址。详情页的「公钥与监听信息」里也有同一项，
和「监听」那行区分开：监听多半是 `127.0.0.1`（后台与 VPN 同机），对外没有意义。

### 5.2 操作

| 想做什么 | 怎么操作 |
|---|---|
| 看服务器在线情况 | 打开页面左栏自动刷新（15 秒） |
| **复制 VPN 服务器地址** | 左栏「公网 …」旁边的「复制」，或详情页「公网地址」行的「复制」 |
| 查看公钥/监听 | 点左栏服务器 |
| 复制白名单指纹 | “复制指纹” |
| 复制公钥给客户端 | “复制公钥 PEM” |
| 申请注册令牌 | 填数量 1–1000 → “申请” |
| 分发令牌 | 每条右侧“复制” |
| 删除发错的令牌 | “删除” → 确认 |
| 修改自己的密码 | 右上“账号” → 当前密码 + 新密码 → 修改 |
| 添加管理员 | 右上“管理员” → 填用户名/密码 → 创建 |
| 备份状态 | “导出 JSON” |
| 退出登录 | 右上“退出” |

## 6. 错误对照

| 提示 | 含义/处理 |
|---|---|
| **401 未授权** | 未登录或会话过期 → 重新 `/login`；不是输入中转令牌 |
| **403 csrf token invalid** | 页面过期/跨站请求 → 刷新页面重新登录 |
| **400 current password incorrect** | 当前密码不对；确认后重试 |
| **429 too many attempts** | 登录失败次数过多 → 等待 15 分钟 |
| **502 连不上中转站** | controller 没起/端口不对/被系统代理劫持 |
| **503 agent 离线** | 该服务器 agent 不在线；不排队 |
| **504 agent 超时** | 命令 10 秒没回执；查 agent/admin_server |
| **401 invalid username or password** | 账号或密码错（不区分用户是否存在） |

## 7. 排障

### 7.1 页面能开但接口全 502

```bash
env | grep -i proxy
ss -ltn | grep 18081
systemctl status scholarvpn-admin-relay
```

程序内部已对 controller 显式禁用系统代理；如果改代码，别删 `ProxyHandler({})`。

### 7.2 服务器列表为空

1. agent 在跑吗？
   ```bash
   ps -ef | grep admin_agent
   tail -n 30 /root/ScholarVPN/server/logs/admin_agent.log
   ```
2. 指纹登记了吗？
   ```bash
   cd /root/ScholarVPN/server
   ./admin-relay.sh list-agents
   ./admin-vpn.sh fingerprint
   ```
3. 登记后重启 controller 了吗？白名单只在启动时读一次。

### 7.3 登录一直失败

- 确认用户名/密码；连续失败 5 次会 429；
- 忘记密码：`python3 manage.py reset-password <用户名>`；
- 看审计/日志：
  ```bash
  sqlite3 /root/ScholarVPN/tools/webadmin/data/webadmin.db \
    'select ts,username,ip,action from audit order by id desc limit 20;'
  journalctl -u scholarvpn-admin-web -n 50 --no-pager
  ```

### 7.4 数据库/权限

```bash
ls -ld /root/ScholarVPN/tools/webadmin/data          # 700
ls -l  /root/ScholarVPN/tools/webadmin/data/webadmin.db  # 600
```

数据库含密码哈希和会话哈希，按敏感文件备份；不要提交到 Git。

## 8. 安全清单

1. 公网必须 HTTPS；Cookie `Secure` 默认随 TLS 开启。
2. 中转管理令牌只在服务端使用，不写进前端/文档/聊天。
3. 每个管理员使用独立强密码（≥10 位），不要共用。
4. 首个管理员用一次性初始化令牌创建；不要重新打开公开注册。
5. 登录限速、CSRF、HttpOnly/SameSite Cookie、会话过期已内置；
   反向代理部署时确保 `WEBADMIN_COOKIE_SECURE=1`。
6. 18081 只绑环回；不要把 controller 直接暴露公网。
7. 定期备份 `tools/webadmin/data/webadmin.db` 和 `server/tls/`（离线加密）。
8. webadmin 以 root 运行时，systemd 已加 `NoNewPrivileges/ProtectSystem`；
   有条件可改用专用用户 + `CAP_NET_BIND_SERVICE`。

## 9. 已知限制

| 限制 | 说明 |
|---|---|
| 请求体 ≤ 8KB | 与 controller 一致 |
| 无分页 | 令牌多时一次拉全量，接近 950 条会触 64KB 帧 |
| 限速是内存态 | 服务重启后计数清零 |
| 无邮件找回 | 忘记密码需服务器上 `manage.py` 重置 |
| 仅单 agent | 一期 controller 限制，多台服务器轮流在线 |
